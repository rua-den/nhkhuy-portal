cách dùng tt-req

1. luồng cơ bản

import curl / nhập tay → test ở tab send → tạo job + đặt interval → job tự bắn hoài → xem ở monitor

2. tab — send one-off

import curldán lệnh curl → bấm parse curl, tự đổ vào form phía dưới. Hỗ trợ: -X -H -d/--data* -F/--form (multipart) -u (basic auth) -b (cookie), line-continuation \ (bash) và ^ (cmd Windows)
form-data fields-F name=value is sent as a text multipart field. File uploads are not supported.
checks (assert)chọn target: status / body / time (ms), op: equals not_equals contains not_contains regex gt lt empty not_empty. Fail → phản hồi đỏ, coi là LỖI
extractrút giá trị ra biến theo json dot-path hoặc regex (group 1 mặc định; full match fallback). Biến dùng dạng {{token}} ở URL/headers/body

3. tab — jobs & step chaining

Job = danh sách step chạy tuần tự. Step sau chỉ chạy khi assert của step trước pass (điển hình: step 1 login → rút token → step 2 gọi API kèm {{token}}).

intervalđơn vị giây. 60 = bắn mỗi phút. 0 = không schedule, chỉ chạy tay. Scheduler checks every second.
schedule chạy liên tụcbật → job bắn mãi (web reload vẫn tự chạy lại). Tắt = paused, chạy bằng nút ▶ run now
dừng khi 1 step faildefault ON — step fail thì bỏ qua các step sau trong lần run đó
variablesbiến tĩnh của job, giá trị ở đây ghi đè bởi extract của step (extract chạy sau)

4. tab — monitor

dot run cuối OK · fail · chưa chạy bao giờ
ok-rate %tỉ lệ run thành công trên lịch sử
click cardbung 12 run gần nhất → click từng run để xem chi tiết từng step (status, assert, response)
auto refreshpoll 3s, tắt ô checkbox nếu muốn freeze

5. mẹo

  • Copy 1 curl từ DevTools (Network → Copy as cURL (bash)) là fastest way dựng request
  • Lịch sử giữ 100 run/job gần nhất trong RAM — restart server là clean, config job nằm trong PORTAL_DATA_DIR/tt-req.json
  • Interval tự động tối thiểu là 60 giây; 0 chỉ chạy thủ công
  • {{var}} không tồn tại → giữ nguyên text, không lỗi

6. REST API (nấu script ngoài)

GET    /api/tt-req/jobs              — list + stats
POST   /api/tt-req/jobs              — tạo job
PUT    /api/tt-req/jobs/:id          — sửa
DELETE /api/tt-req/jobs/:id          — xóa
POST   /api/tt-req/jobs/:id/run      — chạy ngay 1 lần
POST   /api/tt-req/jobs/:id/toggle   — bật/tắt schedule
GET    /api/tt-req/jobs/:id/runs     — lịch sử run
POST   /api/tt-req/send              — gửi one-off
POST   /api/tt-req/parse-curl        — curl → request
