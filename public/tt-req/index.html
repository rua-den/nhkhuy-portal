REFERENCE

Documentation

A quick guide to building and operating TT View jobs.

01

Request steps

Each job contains 1–12 sequential HTTP requests. Supported methods include GET, POST, PUT, PATCH, DELETE, HEAD and OPTIONS.

02

Variables

Use {{variable}} in URLs, headers and request bodies. Extract values from earlier steps to pass data forward.

03

Assertions

Validate status, response time or body content. A failed assertion marks the step unsuccessful; stop-on-fail is enabled by default.

04

Scheduling

Set an interval of at least 60 seconds to enable automatic runs. Interval 0 keeps a job manual-only.

05

Security limits

Requests are restricted to public HTTP(S) destinations on standard ports. Private and reserved IP ranges are blocked; response size and timeout are bounded.

06

Import jobs

Import a JSON array or an object containing a jobs array. Preview first; imported jobs are always paused and must be enabled manually.
